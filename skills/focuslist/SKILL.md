# 专注清单（番茄钟）

本地番茄工作法应用：任务管理、任务分组、番茄钟、系统弹窗提醒、统计、每周回顾、AI 分析。
数据保存在本机 SQLite 数据库，不依赖任何外部服务。

## 启动应用

本地服务已注册为 macOS 后台任务（LaunchAgent：`com.focuslist.server`），开机自启、异常自动重启，锁屏/休眠不受影响；一般无需手动启动服务。

方式一（推荐，macOS 双击）：让用户双击
`~/plugins/focuslist/app/启动专注清单.command`。

方式二（命令行）：

```bash
~/plugins/focuslist/scripts/start.sh
```

启动成功后会打印数据库文件路径和访问地址，并自动打开浏览器
（http://localhost:8765）。如果浏览器没有自动打开，把地址告诉用户。

> 如果服务已经在运行，`start.sh` 会直接打开浏览器而不会重复启动。

## 停止应用

在运行服务的终端按 `Ctrl+C`。

## 使用要点

- 依赖：仅需 Python 3（macOS / Linux 自带，无需安装第三方库）。
- 端口默认 8765；端口被占用时改用其他端口启动：
  `PORT=9000 ~/plugins/focuslist/scripts/start.sh`，并让用户访问对应地址。
- 数据文件 `focuslist.db` 与 `index.html` 在同一目录（`app/`），首次启动自动创建。
- 应用是本地网页：浏览器需要保持打开才能计时和弹系统通知；
  系统通知需用户在应用「设置 → 桌面通知」里开启并授权。
- AI 分析：设置页「AI 分析（可选）」可填 Base URL / API Key / 模型，
  填写后每周回顾的 AI 分析调用真实大模型；不填则用内置本地分析。
  AI 请求由本地 server.py 转发，密钥只保存在本机。

## 常见问题

- 直接双击 `index.html` 打开会提示未连接数据库，必须通过 `server.py` 启动。
- 浏览器调用大模型 API 会跨域失败，这是正常的——应用内 AI 请求走本地服务转发。

## 常用操作（用户直接使用网页即可，无需 CLI）

- 添加任务 / 建分组：网页内操作。
- 开始专注：点任务旁的开始按钮，或点番茄钟圆环。
- 查看统计 / 每周回顾 / AI 分析：网页内对应页面。
- 导出备份 / 清空数据：设置页。
