# 专注清单 · 番茄钟

一个本地运行的番茄工作法应用：任务管理、番茄钟、弹窗提醒、统计、每周回顾 + AI 分析。
所有数据保存在本机 **SQLite 数据库**（`focuslist.db`），不会上传任何服务器。

## 快速开始

**方式一：双击启动（推荐）**

双击本目录下的 `启动专注清单.command`，终端会自动启动服务并打开浏览器。

**方式二：命令行启动**

```bash
cd 本目录
python3 server.py
```

然后浏览器打开 http://localhost:8765 即可使用（启动后会自动打开浏览器）。

> 依赖：仅需 Python 3（macOS / Linux 自带，无需安装任何第三方库）。
> 端口默认为 8765，可通过环境变量修改：`PORT=9000 python3 server.py`

## 数据存储

- 数据库文件：`focuslist.db`（与本文件同目录，SQLite 格式）
- 表结构：`tasks`（任务）、`sessions`（番茄/休息记录）、`settings`（设置）
- 首次启动时，如果检测到旧版本保存在浏览器 localStorage 里的数据，会自动迁移到 SQLite
- 设置页可查看数据库文件路径、导出 JSON 备份、一键清除所有数据

## 常用操作

| 操作 | 说明 |
| --- | --- |
| 添加任务 | 今日任务页输入任务名，可设预计番茄数/优先级/截止/备注/分组 |
| 任务分组 | 顶部或左侧栏 ➕ 新建彩色分组（参考 Focus To-Do），任务可归入分组或收件箱 |
| 开始专注 | 点任务旁的 🍅 进入番茄钟计时；在番茄钟页**点击圆环**即可开始/暂停（空格键也可） |
| 完成提醒 | 专注/休息结束弹出提示 + 音效 + 系统桌面通知（设置里可测试） |
| 查看统计 | 统计页查看今日/7 天图表、周目标、任务排行 |
| 每周回顾 | 回顾页查看周汇总、每日明细、本周任务明细，以及一键生成的 AI 分析 |
| AI 分析 | 设置 → AI 分析（可选）填写 Base URL / API Key / 模型后，周报由真实大模型生成；不填则用本地智能分析 |
| 备份数据 | 设置 → 导出数据 (JSON) |

## 本地服务 API

- `GET  /api/state` — 读取全部数据（tasks / sessions / settings）
- `POST /api/task` — 新增 / 更新单个任务（增量写入）
- `DELETE /api/task?id=xxx` — 删除单个任务
- `POST /api/session` — 新增一条番茄/休息记录（增量写入）
- `POST /api/settings` — 保存设置
- `POST /api/state` — 整库导入（仅用于旧数据迁移，需版本头）
- `DELETE /api/state` — 清空所有数据
- `GET  /api/info` — 返回数据库路径等信息
- `GET  /api/timer` — 读取当前番茄钟状态（供菜单栏计时工具使用）
- `POST /api/timer` — 页面每秒同步番茄钟状态（模式 / 状态 / 剩余秒数）

## 菜单栏计时（可选）

番茄钟运行时会同步状态到本地服务，可用系统菜单栏常驻显示剩余时间：

- 工具位置：`menubar-timer/FocusTimerMenu.app`，显示 🍅/🍵/🌙 + 剩余时间
- 点击菜单栏图标可「打开专注清单」或「退出」
- 已注册开机自启（LaunchAgent：`com.focuslist.menubar-timer`）
- 修改代码后重新构建：`menubar-timer/build.sh`
